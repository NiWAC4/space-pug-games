# Space Pug Games

## Starten

```powershell
npm install
npm run dev
```

Die Seite läuft dann unter `http://127.0.0.1:3000`.

## Design wechseln

Lege eine `.env.local` im Projektstamm an und setze eine der beiden Varianten:

```text
NEXT_PUBLIC_DESIGN_VARIANT=primary
```

`primary` ist das Mops-Design aus `primärdesign/Seitenmockup_Nr1.png`.
`secondary` verwendet die fünf Einzelbilder in `sekundärdesign/`.

Texte, Kontaktlink, Imprint, Scroll-Navigation und Effekte bleiben bei beiden Varianten gleich.
